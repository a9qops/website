# Visual Identity — Editorial Timeline
## Concept
A high-end film-title-sequence/editorial-magazine identity inspired by the language of professional editing—without imitating editing software.

## Signature motifs
Selective timecode metadata, thin timeline rules, crop marks, project numbering, film-frame windows, playhead-like transitions, masked title reveals, hard cuts and restrained dissolves.

## Palette
Near-black Ink, warm off-white text, graphite surfaces, muted metadata gray, and ONE signature finishing accent chosen as a brand decision. Do not randomly alternate cyan and amber.

## Typography
Bold editorial display typography + highly readable sans/grotesk. Arabic typography is an equal visual partner. Monospace/timecode type is metadata-only.

## Layout
Asymmetric editorial grids, large media fields, intentional whitespace, occasional edge-to-edge work, production-note metadata alignment. Mobile preserves hierarchy rather than collapsing into generic cards.

## Motion
Editing-inspired transitions, clip-window reveals, subtle parallax and shared project transitions. Respect reduced motion.

## Glass / Cursor
Glass is a utility treatment, not the identity. Custom cursor is optional desktop enhancement only.
