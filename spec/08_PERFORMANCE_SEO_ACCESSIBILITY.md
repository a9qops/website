# Performance, SEO & Accessibility
## Performance
Poster-first YouTube embeds; optimized hero reel; known image dimensions; lazy media; avoid many active iframes; transform/opacity motion; profile heavy effects.

## SEO
Localized metadata, canonical URLs, hreflang, project OG metadata, sitemap, robots, published-only indexing, structured data where appropriate.

## Accessibility
Semantic headings/navigation, keyboard support, visible focus, CMS-managed alt text, labeled video embeds/forms, contrast, reduced motion, Arabic RTL reading/focus-order verification.
