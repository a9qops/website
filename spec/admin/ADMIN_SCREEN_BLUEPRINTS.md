# Admin Screen Blueprints
## Dashboard
Quick actions: New Project, Edit Home, Edit About; real draft/published/recent-edit data only.

## Projects
Search/filter + New Project. Dense rows: poster | title | state | featured | order | updated | edit.

## Project Editor
Desktop two-column / mobile stacked. Main: EN/AR title/description, YouTube URL + preview, metadata. Side: poster, state, featured, order, Save/Publish.

## Content Editor
Page selector + EN/AR structured fields + preview/save.

## Settings
Contact/social/default SEO values.
