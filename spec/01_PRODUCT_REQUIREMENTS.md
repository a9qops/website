# Product Requirements
## Audience
High-end agencies, directors, producers, brands and collaborators.

## Home
Cinematic hero, concise positioning, featured real projects, owner-managed supporting copy, contact CTA.

## Work
Responsive project index, owner-managed published projects, optional real taxonomy/filtering, no runtime dummy projects.

## Project Detail
YouTube player, title, client/year/services only when supplied, EN/AR description, poster, optional credits, adjacent project navigation where approved.

## About / Services / Contact
All editorial copy must be owner-editable in EN/AR. Contact/social values come from Site Settings.

## Admin requirements
Owner can edit Home/About/Services/Contact text; create/edit projects; paste YouTube URL; upload poster/thumbnail; preview; draft/publish; feature/reorder projects; edit contact/social/SEO settings.

## Localization
Public editorial content supports English LTR and Arabic RTL as equal experiences.
