# Information Architecture
## Public routes
`/[locale]`, `/[locale]/work`, `/[locale]/work/[slug]`, `/[locale]/about`, `/[locale]/services`, `/[locale]/contact`.

## Admin routes
`/admin/login`, `/admin`, `/admin/content`, `/admin/projects`, `/admin/projects/new`, `/admin/projects/[id]`, `/admin/settings`.

Admin is not exposed in public navigation and all mutations are server-authorized.
